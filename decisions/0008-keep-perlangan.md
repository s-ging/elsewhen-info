# 0008 — Keep the name Perlangan

**Date:** 2026-11-11 (recorded 2026-11-12)
**Decided by:** Krischan
**Status:** accepted

## Context

"Perlas" is a Spanish loanword and "Pearl of the Orient" is a colonial-era epithet, so the name breaks the anti-colonial naming idea.

## Decision

Keep it. It sounds like a real place. Either give it a one-line in-world explanation or treat the pedantic comments as engagement. Native fallback root if ever needed: *mutya*.

## Alternatives considered

- Lusayas, Puluan, Dagatnon: considered, not picked.
- Unluvis: rejected, sounds like a modern acronym.
