# Research note

1. Copy `templates/research.md` to `research/YYYY-MM-DD-short-topic.md`. Put screenshots and source files in `research/files/` with the same date prefix.
2. Start with a **Method** line: what was looked at and how.
3. Write findings in your own words. Give every fact its source (a link with the date read, a book and page, "Krischan said") and mark guesses as guesses. Flag anything disputed among historians.
4. End with **What this means for the series** and **Next steps**.
5. Update the files this changes: `series/` for scripts and the bible, `project/open-questions.md` for new questions, `project/status.md` if priorities moved.
6. Add a row to `research/README.md`.
7. Finish with the `session-log` skill.

Keep quotes from sources short; summarize instead of copying.
