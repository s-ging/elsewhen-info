# Elsewhen

Knowledge base for **Elsewhen**, a faceless short-form channel of alternate-history "what if" miniseries for Reels, Shorts and TikTok. Built by Krischan.

**The short version:** each miniseries changes one structural condition in real history and follows it forward, told like a strategy-game cutscene: typed date stamps, letterboxed dialogue, war-table maps, no narrator. Every episode ends on what really happened. The lead miniseries follows Perlangan, an alternate Philippines that never fell to Spain.

**Start with [AGENTS.md](AGENTS.md)**, then [project/status.md](project/status.md).

## Starting a new session

- **Claude (claude.ai or the Claude app):** start the chat with: "We're working on the Elsewhen knowledge base in `s-ging/elsewhen-info`. Pull it and read AGENTS.md before anything else."
- **Claude Code on your computer:** clone the repo, open a terminal in it and run `claude`. `CLAUDE.md` loads automatically.
- **Other AI tools (Cursor, Codex and similar):** open the repo; they read `AGENTS.md`.
- **Chatbots without repo access:** paste `AGENTS.md`, `project/status.md` and `series/bible.md` at the start.

Every session ends by committing and pushing its changes.

No plain-text passwords or keys; see [AGENTS.md](AGENTS.md#credentials).
